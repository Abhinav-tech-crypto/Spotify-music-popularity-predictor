# Spotify-music-popularity-predictor
This project aims to predict the popularity of Spotify tracks using machine learning algorithms. By analyzing various features such as song attributes (e.g., tempo, danceability, loudness) and metadata (e.g., genre, release year), the model predicts the popularity score of a track. The project uses Google Colab for easy and interactive exploration, leveraging Python libraries such as Pandas, Scikit-Learn, and XGBoost.

Project Overview
The objective of this project is to predict the popularity of Spotify songs based on several musical and metadata features. These features include attributes like the track's danceability, acousticness, tempo, and more. The final model provides a prediction score that reflects how popular a track might be.

Key Features:
Data Preprocessing: Cleaning and transforming data to prepare it for machine learning.
Feature Engineering: Creating meaningful features like interaction terms, genre encoding, and more.
Model Training: Building regression models like Random Forest, XGBoost, and Linear Regression to predict popularity.
Model Evaluation: Evaluating the model using common regression metrics such as RMSE, MAE, and R².
Google Colab Integration: Easy-to-use Colab notebooks to run and experiment with the model directly in the cloud.
Visualization: Visualizing the relationship between song features and their popularity using plots and graphs
